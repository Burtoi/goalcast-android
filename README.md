# ⚽ GoalCast pentru Android

Predicții de fotbal din **sute de competiții din toată lumea** (inclusiv Liga 1): 1X2, dublă șansă, Peste/Sub goluri,
GG/NG, scoruri exacte, clasamente cu cele mai sigure selecții și bilet zilnic.
Totul rulează **în telefon**, fără server și fără cont.

## Descarcă

**[GoalCast.apk (ultima versiune, 74 MB)](https://github.com/Burtoi/goalcast-android/releases/latest/download/GoalCast.apk)**

1. Deschide fișierul descărcat.
2. Permite instalarea din această sursă când Android întreabă (dacă Play Protect avertizează: „Instalează oricum”).
3. Prima pornire durează 1–2 minute (se pregătește motorul); apoi pornește repede.

Cerințe: Android 7.0+ pe 64 de biți (arm64), ~400 MB liberi. Se actualizează singură când ai internet.

## Important

Predicțiile sunt estimări statistice, **nu garanții** și nu sunt sfaturi de pariere. Fotbalul are mult noroc; în
testele pe istoric modelul nu bate cotele caselor de pariuri. Datele vin din surse neoficiale (ESPN, Livescore,
football-data.co.uk) care se pot schimba oricând.
